1 네트워크 핵심 개념 (실생활 비유)

이론 학습

네트워크 (Network)

컴퓨터들이 서로 대화할 수 있도록 연결된 '도로망'입니다. 길(선/무선)이 연결되어 있어야 택배나 편지가 오갈 수 있습니다.

IP 주소 (IP Address)

인터넷 세상에서 내 기기(PC, 스마트폰)가 가진 고유한 '집 주소'입니다. 편지를 보낼 때 주소가 꼭 필요합니다.

패킷 (Packet)

데이터를 빠르게 전송하기 위해 잘게 쪼갠 '작은 택배 상자'입니다. 목적지에 도착하면 하나로 조립됩니다.

DNS (도메인 네임 시스템)

인터넷 세상의 '전화번호부'입니다. 외우기 힘든 숫자 IP 대신 www.school.com 같은 이름을 IP 주소로 바꿔줍니다.

2 컴퓨터는 왜 0과 1(2진법)만 사용할까?

체험 실습

컴퓨터 속 수십억 개의 '전기 스위치'

사람은 손가락 10개로 0~9를 쓰는 10진법을 쓰지만, 컴퓨터 내부 트랜지스터 스위치는 전기가 흐르는 켜짐(1)과 꺼짐(0) 2가지 상태만 인식합니다.

따라서 컴퓨터는 이 0과 1(비트, Bit) 스위치들을 여러 개 조합해서 숫자, 글자, 영상까지 나타냅니다!

전구 스위치를 클릭해 켜고(1) 끄며(0) 10진수 숫자를 만들어보세요!

3 데이터 크기 단위 (Bit ~ GB)

4 유선 네트워크 vs 무선 네트워크 비교

이론 비교

컴퓨터실 (유선 LAN)

랜선 물리 연결
  • 특징: 네트워크 랜선 케이블을 컴퓨터에 직접 꽂아 통신합니다.
  • 장점: 전파 방해가 없어 속도가 매우 빠르고 끊김이 없이 안정적입니다.
  • 단점: 선이 닿는 위치에서만 써야 하므로 이동이 불가능합니다.

교실 와이파이 (무선 WLAN)

공기 중 전파 연결
  • 특징: 공유기(AP)에서 쏘아주는 전파(무선 신호)를 이용하여 연결합니다.
  • 장점: 스마트폰, 노트북을 들고 다니면서 어디서나 자유롭게 사용합니다.
  • 단점: 장애물이나 거리가 멀어지면 속도가 느려지거나 끊길 수 있습니다.

5 와이파이 접속과 DHCP (IP 대여 및 반환 실습)

체험 실습

한정된 IP 주소를 알뜰하게 나눠 쓰는 원리 (DHCP)

전교생이 1,000명이라고 해서 학교 공유기가 1,000개의 IP 주소를 모두 켜둘 필요는 없습니다.

공유기(DHCP)는 한정된 IP 주소를 가지고 있다가, 와이파이를 켜는 학생에게만 빌려주고(대여), 와이파이를 끄면 다시 회수(반환)하여 다른 사람에게 돌려줍니다!

공유기 IP 주소 목록 (총 5개)

스마트폰을 클릭해서 와이파이를 켜고(대여) 꺼보세요(반환)!
